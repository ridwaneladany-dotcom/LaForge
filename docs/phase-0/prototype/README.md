# Prototype interactif de phase 0

Ce prototype matérialise les décisions de cadrage de LaForge sans choisir la future stack applicative.

## Parcours disponibles

1. Découvrir le principe dans l'onboarding de première visite.
2. Choisir une tâche et une durée.
3. Lancer un sprint avec `Forger 15 min`.
4. Tester la saisie uniquement vers l'avant et la récupération après rechargement.
5. Ouvrir la sortie volontaire qui conserve le texte.
6. Utiliser `Aperçu du bilan` pour atteindre immédiatement l'écran de fin.
7. Réviser le texte ou préparer la tâche suivante.

## Lancement local

Le dossier est autonome : ouvrir `index.html` directement ou le servir avec le serveur statique de son choix. Aucune configuration ni aucun port particulier n'est requis.

Le prototype utilise uniquement HTML, CSS et JavaScript natifs. Son code n'est pas la fondation technique de l'application finale.
